# Plan: Web UI to 9+ (Phased: Test Harness → UX/Metrics → Accessibility)

## Goal
Raise the Web Studio score from ~7.5 to 9+ by (1) retiring the "no live browser
verification" cap with an automated headless UI suite, then (2) upgrading UX and
surfacing the honest/advanced metrics, then (3) meeting WCAG-AA basics.

Scope = **Option C via harness Option A** (Playwright-Python + pytest, CDN libs
vendored locally). Implementation requires an implementation-capable agent
(source edits + `pip`/`playwright install`). This plan agent cannot execute it.

## Baseline (verified in repo)
- Front-end: `web/index.html`, `web/js/app.js`, `web/js/cfg_visualizer.js`, `web/js/metrics_chart.js`.
- Server contract: `api/server.py` `/api/compile`, `/api/samples`, `/api/export`; static mount serves `web/`.
- CDN deps (make app break offline): `index.html:12-16` = Chart.js, Cytoscape 3.28.1, dagre 0.8.5, cytoscape-dagre 2.5.0.
- Tests: 38 passing under pytest. No `conftest.py`, no pytest config, no CI, no `httpx`.
- Already-computed-but-unsurfaced server fields: `advanced_compression.final_advanced_bitstream_bytes`, `final_advanced_compression_percent`; `constant_pool.stats.net_bytes_saved`, `overhead_exceeds_savings`, `net_compression_percentage`, `pool_overhead_bytes`.
- Known crude UX: `alert()` at `app.js:137` (compiler error), `app.js:390` (empty export), `app.js:414` (export failure).
- Tabs (`index.html:88-108`) are `<button class="tab-btn" data-tab=...>` with no ARIA/keyboard pattern; handler at `app.js:52-77`.
- CFG edges are color-only coded (`cfg_visualizer.js` `branch_true` green / `branch_false` red).

## Resolved decisions (defaults; override if desired)
- **Harness**: Playwright-Python + `pytest-playwright`, headless Chromium. Dev deps in new `requirements-dev.txt`.
- **Server-under-test**: session-scoped pytest fixture boots `uvicorn` (`api.server:app`) on an ephemeral port in a background thread; yields base URL; signals `server.should_exit` on teardown.
- **Vendoring**: download the 4 libs into `web/vendor/` (pin exact versions) and repoint `index.html`. Fixes real offline-fragility too.
- **Test introspection hook**: attach the two Cytoscape instances to `window` (e.g. `window.__cfgViz`, `window.__domViz`) in `cfg_visualizer.js` so tests can assert `.cy.nodes().length` and rendered width (proves the `cy.resize()` fix).
- **Error UX**: replace all `alert()` with a non-blocking toast (aria-live) + the existing status badge + inline error-line highlight in the editor gutter.
- **Metrics**: surface Advanced SoA bitstream in Overview + add it as a 5th bar in the chart; show constant-pool net/overhead with a warning badge when `overhead_exceeds_savings`.
- **Accessibility**: ARIA tab pattern + roving-tabindex keyboard nav, `aria-live` status/toast, non-color-only edge cues (T/F labels), `focus-visible`, `prefers-reduced-motion`.
- **Out of scope (default)**: axe-core (@axe-core/playwright is Node — avoid adding a Node toolchain); mobile/responsive redesign; i18n.

## Phase 1 — Automated UI test harness (retires the verification cap)

1. **Vendor front-end libs**: create `web/vendor/` with pinned `chart.min.js`, `cytoscape.min.js`, `dagre.min.js`, `cytoscape-dagre.min.js`; repoint `index.html:12-16` to `js/vendor/...` paths (served by the static mount). Verify the Studio loads with networking disabled.
2. **Add dev deps**: `requirements-dev.txt` with `pytest-playwright` (pulls `playwright`). Document `playwright install chromium`.
3. **`conftest.py` (repo root)**: session fixture `live_server` → starts uvicorn thread on port 0, resolves bound port, waits for `/api/health` 200, yields `http://127.0.0.1:<port>`, then `should_exit=True` + join.
4. **Expose viz instances on `window`** in `cfg_visualizer.js` (`getCfgVisualizer`/`getDomTreeVisualizer`).
5. **`tests/ui/test_studio_ui.py`** (headless Chromium):
   - App loads; default sample auto-compiles; `#stat-final-ratio` text is not `0.0%`.
   - Tab switch to `cfg-tab`: `window.__cfgViz.cy.nodes().length > 0` **and** rendered graph width `> 0` (asserts `resize()`+`fit()` fix; would fail with the old collapsed-pane bug).
   - CFG view radios (raw/ssa/optimized) re-render without error.
   - Raw-CFG correctness: load `sample4`, raw CFG/`#raw-tac-code` contains `ghost_var`; optimized view does not (guards the server pre-SSA snapshot).
   - Export: clicking `#btn-export` triggers a download named `compiled_compressed_ir.cir` (`expect_download`).
   - SSA tab renders dominator tree (`window.__domViz.cy.nodes().length > 0`).
6. **CI**: `.github/workflows/ui.yml` — setup Python, `pip install -r requirements.txt -r requirements-dev.txt`, `playwright install --with-deps chromium`, run `python -m pytest` (unit + UI). Cache the Playwright browser.

**Phase 1 exit**: unit 38 green + UI suite green locally and in CI; app verified offline.

## Phase 3 — Accessibility (WCAG-AA basics)

12. **ARIA tab pattern**: `role="tablist"` on the tab bar; `role="tab"`, `aria-selected`, roving `tabindex` on each `.tab-btn`; `role="tabpanel"`/`aria-labelledby` on panes. Update `app.js:52-77` to add ArrowLeft/Right/Home/End nav and Enter/Space activation; preserve the existing `cfg`/`ssa` resize-on-activate logic.
13. **Live regions**: `aria-live="polite"` on `#compiler-status`; errors via the assertive toast.
14. **Non-color edge cues** (`cfg_visualizer.js`): give `branch_true`/`branch_false` edges `T`/`F` text labels (and/or distinct line-style) so meaning survives color-blindness; keep `jump` dashed.
15. **Visual focus & motion**: `:focus-visible` outlines on interactive controls; `@media (prefers-reduced-motion: reduce)` disables Cytoscape layout animation and Chart.js animation.

**Phase 3 exit**: tab list fully keyboard-operable; status/errors announced; edges distinguishable without color; reduced-motion honored. Add Playwright keyboard-nav assertion (Arrow keys move tabs, Enter activates, focus visible).

## Risks & mitigations
- **uvicorn thread teardown flakiness** → use `server.should_exit` + bounded join; health-poll before tests.
- **Playwright browser in CI** (size/time) → `--with-deps chromium` only + cache.
- **Vendored version drift** → pin exact versions; record source URLs in a `web/vendor/README`? (plan agent cannot create; implementer adds a comment in `index.html`).
- **`window` test hooks** → harmless globals; namespaced `__`-prefixed.
- **Edge-label clutter** on dense graphs → short single-char `T`/`F` labels only on branch edges.

## Rollout
Land Phase 1 first (foundation + CI gate), then Phase 2, then Phase 3 — each phase independently shippable and guarded by the suite from Phase 1.
